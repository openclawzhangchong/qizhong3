# qizhong3 · 信息基础知识试卷讲评课件

2025级《信息基础知识》期中考试卷互动讲评课件。

## 功能
- 103 道题（单选60 / 多选10 / 判断20 / 填空10 / 综合3），按题型筛选、题号跳转
- 每题免费火山 TTS 朗读（translate.volcengine.com 公开接口），失败自动降级浏览器语音
- 随机抽人：每题旁按钮，模态滚动抽签 + TTS 叫名字，36 人不重复
- 客观题点击答题，正确/错误双音色反馈，答案解析
- 手机端适配，投屏友好

## 使用
直接打开 ，或访问 Cloudflare Pages 部署地址。朗读引擎可在右上角 ⚙️ 中切换。
