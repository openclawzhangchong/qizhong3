## 课件功能

- 103 道题（单选 60 / 多选 10 / 判断 20 / 填空 10 / 综合 3），按题型筛选、题号跳转
- 每题朗读：默认走火山免费音色（`translate.volcengine.com` 公开接口，免鉴权），失败自动降级浏览器语音；设置面板可切换 7 种火山音色 / 浏览器语音 / 火山官方 API
- 随机抽人：每题旁按钮，模态框滚动抽签 + TTS 叫名字，36 名学生不重复抽取，可重置
- 客观题上台点击作答，正确 / 错误双音色反馈，随后展开答案与解析
- 填空题、综合题展示参考答案与解析；第 9、63、68、102 题等争议题在解析里做了讲评标注
- 手机端适配，教室投屏友好
